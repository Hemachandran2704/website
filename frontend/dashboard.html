System Roles Definition

🛡️ Administrator (ADMIN)

System Role

Full administrative privileges across all dynamic modules, user accounts, security policies, system configuration, audit logs, and document approvals.

  • User management (Create, Edit, Deactivate, Block)
  • Full CRUD on 17 Dynamic CMS modules
  • Support ticket escalation and resolution
  • Document review, approval, and rejection
  • System settings and analytics inspection

👤 Standard User (USER)

Default Role

Standard authenticated account with access to personal dashboard, own documents, personal activity history, calendar schedules, and support ticketing.

  • Access personal user dashboard & overview
  • Create & track own support tickets
  • Upload & download own documents
  • Manage personal profile, schedules & preferences
  • Strictly prevented from accessing admin controls
